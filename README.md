# English Studio

**从轻松聊天开始，把你的真实经历变成能直接说出口的英语。**

想练口语，却不知道聊什么？English Studio 每次只问一个生活中的小问题。你回答一两句话，它会顺着你的经历继续聊，在旁边逐步整理一份属于你的口语范例。

适合希望积累个人口语素材、练习日常表达，或为 IELTS / TOEFL 口语练习寻找内容的人。无需一次准备完整故事，也不用先给自己定级。

## 你可以做什么

- **从熟悉的话题开始。** 打开网页就有开场问题，也可选择住处、工作学习、食物、音乐、周末等话题。
- **像聊天一样练习。** 每次回答一两句话即可。没思路时可以用中文求助，或直接说“换个话题”。
- **得到克制的语言反馈。** 展开“本轮语言反馈与微调”，查看语法、句式检查和建议表达。对话区只保留回应与追问。
- **使用新问题的回答提示。** 输入框中的浅色英文是回答当前问题的句型支架；方括号里的内容由你自己填写。参考文字不会自动发送。
- **实时形成口语范例。** 右侧草稿将已聊到的信息组织成第一人称答案，可点击标题收起或展开。
- **发现可复用表达。** 草稿内多色高亮可迁移到其他话题的短语，颜色不代表分数或等级。
- **直接修改草稿。** 可以在正文里增删、修改。手动编辑后，后续自动更新会保留你的正文。

例如，你先说：

> My comfort food is rice noodle.

接着聊到你通常买着吃，素材可能逐步变成：

> My comfort food is rice noodles. I usually buy them rather than make them myself.

只有当你继续分享购买地点、喜欢的原因或一次具体经历，答案才会进一步丰富。它不会为了把段落写长，替你编造一家店或一个故事。生成内容仍请你核对。

## 开始使用

需要 **Python 3.10 或以上版本**、现代浏览器，以及一个可用的 **DeepSeek API Key**。项目仅使用 Python 标准库，不需要安装第三方 Python 包。

以下命令适用于 macOS / Linux。

### 1. 下载项目并创建环境

```sh
git clone https://github.com/ovOvo101/deepseek-agent.git
cd deepseek-agent
python3 -m venv .venv
source .venv/bin/activate
```

### 2. 配置一次密钥

在 [DeepSeek 开放平台](https://platform.deepseek.com/)创建 API Key，然后运行：

```sh
python configure_key.py
```

在终端提示中粘贴密钥并回车。输入不会显示。密钥保存在本机 `.local-key.json`，文件仅当前账户可读写，且已排除 Git 上传。不要将密钥或此文件发给别人。

若已设置 `DEEPSEEK_API_KEY` 环境变量，服务会优先使用它。更换本地密钥时，重新运行配置脚本即可。

### 3. 启动网页

```sh
python server.py
```

打开 **[http://127.0.0.1:8765](http://127.0.0.1:8765)**。

直接回答页面上的开场问题，点击“发送回答”。模型栏预填 `deepseek-flash`；若你的账户不支持该模型，请改为账户实际可用的模型 ID。后端会通过 DeepSeek 模型列表接口核验，不保证预填名称始终有效。

不要直接双击 HTML 文件，网页需要本机服务。终端保持运行；结束使用时按 `Ctrl+C` 停止服务。

### 下次使用

无需重复配置密钥：

```sh
cd deepseek-agent
source .venv/bin/activate
python server.py
```

## 关于素材草稿

右侧显示的是**基于当前对话生成的个人口语范例**，而不是逐句翻译或第三人称的聊天摘要。信息较少时答案会很短，细节充足后再自然展开。对话不按考试计时，也不保证生成正式考试的完整答案或分数。

直接编辑草稿后，正文进入手动保留状态，避免你的修改被下一轮覆盖。手动内容目前只在网页工作区内，不会自动作为新的事实发送给外教。要让外教据此追问，请在聊天输入框中告诉它。

**目前不提供聊天或草稿的自动保存、收藏和导出入口。刷新网页或切换话题会清空当前对话与草稿，请先复制需要保留的文字。** 未修改的草稿会随每轮回答更新；已手动编辑的正文需开启新对话后才重新自动生成。

## 数据与使用费用

- 网页服务仅监听本机 `127.0.0.1`，不提供公网访问或多人账户。
- 密钥在 Python 后端读取，不返回浏览器；服务也不提供项目目录或密钥文件下载。
- 学习目标、当前回答与必要对话历史会发送至 DeepSeek。不要输入不愿发送给该服务的私人信息。
- 每轮包含语言反馈、追问和素材整理，通常需要多次模型请求，因此会产生 API 用量，也可能需要等待一段时间。
- 初始生活问题来自本地自拟题库，不消耗 API。刷新或关闭页面不保证取消已经发送的模型请求。
- AI 的纠错、润色和素材整理可能出错，请以你的真实经历为准。当前是文字练习，不支持语音输入、发音评测或正式考试评分。

## 常见问题

**连接不上网页？**

确认 `python server.py` 正在运行，并访问 `http://127.0.0.1:8765`。如果提示端口被占用，检查是否已经启动了另一份服务。

**提示模型不可用或 HTTP 错误？**

检查密钥、API 账户状态与余额，并确认模型 ID 在你的账户可用列表中。不要把包含密钥的截图用于排查。

**回复失败，输入会丢失吗？**

请求失败时，网页保留本次输入，可再次发送。如果只有素材整理失败，正常的对话仍会显示，右侧保留上一版草稿，后续回答时会再尝试更新。

**更新代码后没有变化？**

停止终端中的服务，重新运行 `python server.py`，再刷新网页。仅刷新页面不会重新加载 Python 后端代码。

**话题按钮会怎样处理现有对话？**

它会开始一个新话题。已有回答或未发送草稿时会先提示确认，请先复制需要保留的内容。

## Agent 如何工作

用户每次只需说一点，后台负责组织本轮行动：

```text
学习目标 → 观察用户回答 → 调用反馈工具
        → 根据观察调整追问 → 等待用户回答
        → 调用素材整理工具，更新右侧范例
```

模型选择工具参数，Python 校验原话引用、字段格式和执行顺序。格式错误会作为观察返回模型修正，单次教学或素材整理最多进行 6 步，避免无限循环。素材工具只接受用户原话作为事实证据；这项校验不能证明整篇改写完全忠实，仍需用户核对。

这不是独立 checker 多智能体系统，反馈与教学由同一模型完成。展开“查看 Agent 执行过程”可以看到实际工具执行记录。

## 开发与测试

```sh
python -m unittest -v
```

测试使用模拟 API，不消耗真实模型用量，覆盖反馈顺序、参数校验、错误恢复、素材原话引用、网页接口和文件访问边界。通过测试不等于真实模型在所有输入下均能正确教学。

```text
server.py           本机网页服务
api.py              DeepSeek API 客户端
tutor.py            对话与素材整理的工具循环
speaking_prompt.py  自然口语及范例生成规则
configure_key.py    本地密钥配置
web/index.html      聊天与实时素材网页
test_tutor.py       教学和素材工具测试
test_server.py      网页接口集成测试
```
